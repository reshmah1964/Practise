# Testing1233

A small Python learning project with test scripts for working with test-run data:

- Find the slowest and fastest test.
- Group test names by status, including invalid statuses.
- Calculate the passed-test percentage from user-provided totals.

## Run

Requires Python 3. Run the script from a terminal:

```powershell
python basic_functional_progras.py
```

When prompted, enter the total number of tests and the number that passed.
